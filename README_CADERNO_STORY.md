# EVRYLUX — atualização da narrativa do Cérebro

Esta atualização altera a seção imersiva da home para contar uma história mais próxima do problema real:

1. a pessoa anota em um caderno para não esquecer;
2. com o tempo, essas páginas deixam de ser revisitadas;
3. no digital, as anotações também podem acabar espalhadas em blocos, arquivos e conversas;
4. o EVRYLUX reúne e organiza conceitos, perguntas e relações;
5. perguntas e revisões ajudam a trazer de volta o que importa;
6. o histórico continua organizado e a arquitetura é apresentada como protegida por criptografia.

## Instalação

```bash
cd ~/Documentos/PlatformIO/Projects/ghost-core
unzip -o ~/Downloads/EVRYLUX_CADERNO_STORY_UPDATE.zip -d .
```
