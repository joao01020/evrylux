# EVRYLUX — Ícone de entrada atualizado

Troca o antigo ícone de seta do botão `Entrar` por um símbolo original de:
- equipe/pessoas;
- configuração/gestão.

Mantém:
- central de notificações;
- ícones de suporte e demo;
- avatar quando autenticado;
- botão `Minha área`;
- toda a lógica atual do Header.

## Instalar

```bash
cd ~/Documentos/PlatformIO/Projects/ghost-core
unzip -o ~/Downloads/EVRYLUX_HEADER_ICONE_EQUIPE.zip -d .
```

## Testar

```bash
cd ~/Documentos/PlatformIO/Projects/ghost-core/website
npm run build
npm run dev
```
