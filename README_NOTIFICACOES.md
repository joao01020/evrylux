# EVRYLUX — Header com notificações modernas

Inclui:
- ícone bonito de conversa para Suporte;
- ícone de formulário/fila para Fila do Demo;
- sino central de notificações;
- badge vermelho com quantidade;
- pulso discreto quando existem novidades;
- painel de notificações ao clicar no sino;
- ao entrar em Suporte ou Fila do Demo, a marcação é considerada vista localmente e some;
- quando surgirem novas entradas acima do que já foi visto, o badge reaparece;
- preserva avatar e botão Minha área.

Instalação:

```bash
cd ~/Documentos/PlatformIO/Projects/ghost-core
unzip -o ~/Downloads/EVRYLUX_HEADER_NOTIFICACOES.zip -d .
```

Teste:

```bash
cd ~/Documentos/PlatformIO/Projects/ghost-core/website
npm run build
npm run dev
```
